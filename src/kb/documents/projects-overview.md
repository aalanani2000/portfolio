# Projects Overview

Abdulrahman has built four main portfolio projects spanning AI integration, robotics, LLM engineering, and classical machine learning (مشاريع عبدالرحمن).

## AL ROUF AI Integration Platform

Flagship. End-to-end AI integration platform: RFQ-to-CRM automation with n8n + OpenAI, a FastAPI quotation microservice with SQLite + Docker + automated tests, and a bilingual English/Arabic RAG knowledge service with citation enforcement and refusal logic. Repository: github.com/aalanani2000/al-rouf-ai-integration-assessment.

## Autonomous Fire Detection & Extinguishing Drone

Graduation project, grade A+, six-person team. YOLOv8 fire detection running onboard on Raspberry Pi 3 (mAP@50 ≈ 0.824, precision ≈ 0.83), APM 2.8 / ArduCopter flight stack, PS4 ground control, AFO extinguishing-ball payload design. Closed-source academic project.

## LLM Engineering Journey

Hands-on path into production LLM engineering: AI job description analyzer with structured JSON output, dual-backend technical tutor streaming from OpenAI + local Ollama simultaneously. Roadmap continues into RAG pipelines, agents, and fine-tuning. Repository: github.com/aalanani2000/llm-engineering-journey.

## ML Internship Project (Codveda)

Four classical ML tasks in Google Colab: house price regression R² ≈ 0.66, sentiment classification accuracy ≈ 0.80 (TF-IDF + neural network), churn prediction accuracy ≈ 0.95 / ROC AUC ≈ 0.886 (Random Forest), stock trend visualization. Trained model artifacts saved as .pkl files.
