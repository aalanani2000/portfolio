# Project: LLM Engineering Journey

Repository: github.com/aalanani2000/llm-engineering-journey
A structured, hands-on path into production LLM engineering following the "Become an LLM Engineer in 8 Weeks" course by Ed Donner — working tools, not notes (رحلة هندسة النماذج اللغوية).

## Completed builds

Day 1 — AI Job Description Analyzer: paste any AI/ML job description, get match score, skills you have, gaps to close, and a prioritized action plan. Key engineering: structured JSON output from LLMs, system/user prompt separation, defensive output parsing.

Week 1 — AI Technical Tutor: ask any technical question and get deep structured explanations from two LLM backends simultaneously — OpenAI GPT with live streaming and a free local model via Ollama (Gemma/Llama/Mistral class). Key engineering: streaming API, live display updates, local LLM inference, expert system-prompt design.

## Roadmap

Week 2 RAG pipeline (embeddings, vector databases), Week 3 LLM agent with tool use and memory, Week 4 fine-tuning pipeline (LoRA/QLoRA/HuggingFace/vLLM), Weeks 5–8 full production AI app.

## Stack

OpenAI and Anthropic APIs, Ollama local models, LangChain/LangGraph (planned), ChromaDB/Pinecone (planned), FastAPI + Docker deployment (planned), AWS SageMaker, Oracle OCI.
